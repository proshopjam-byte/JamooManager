Windows application for lodging operations

宿泊業務を、
ひとつの画面でもっと分かりやすく。

JamooManagerは、小規模宿泊施設の予約取込、予約カレンダー、顧客管理、 チェックイン帳票、部屋割りなどの日常業務を支援するWindowsアプリです。

JamooManagerの基本方針
  • 小規模宿泊施設の実務に合わせた設計
  • 予約・顧客データは原則として利用者のPC内に保存
  • 予約サイトの原資料と照合できる補助ツール

主な機能

予約情報の取込と整理

CHILLNN、Booking.com、楽天トラベル、じゃらんnet等の予約情報を整理し、 カレンダーで確認しやすくします。

チェックイン業務

チェックインシート、チェックインカード、連泊表示、客室設定、 自動部屋割りなどを支援します。

顧客・料金管理

顧客情報、添付資料、OCR補助、直接予約料金、月間売上などを Windows PC上で管理します。

Googleユーザーデータの利用

JamooManagerは、利用者が明示的に許可した場合に限り、Gmail APIの 読み取り専用権限を使って宿泊予約通知を検索・取得します。取得した情報は、 予約取込と関連する宿泊業務機能の提供にのみ使用し、広告、販売、信用評価、 その他の無関係な目的には使用しません。

Gmailのメールを送信・変更・削除する権限は要求しません。認証トークンと 取り込んだ予約情報は原則として利用者のWindows PC内に保存され、 JamooManager運営者のサーバーへ自動送信されません。詳細は プライバシーポリシーをご確認ください。

ご利用にあたって

JamooManagerは宿泊業務を補助するソフトウェアです。在庫一元管理システムや 各予約サイトの公式記録に代わるものではありません。予約日、人数、客室、料金、 食事、キャンセル等は、必ず各予約サイトの管理画面や通知と照合してください。
