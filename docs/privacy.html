プライバシーポリシー

制定日：2026年8月21日　最終改定日：2026年8月25日

1. 事業者

タケスポーツサービス（代表者：武井 晋司。以下「当事業者」）は、 JamooManagerの販売、ライセンス管理およびサポートに伴い取り扱う情報を、 関係法令および本ポリシーに従って適切に管理します。

2. 取得する情報

当事業者または本ソフトは、次の情報を取り扱う場合があります。

  • 購入者の氏名、事業者名、施設名、連絡先、購入履歴、支払状況
  • ライセンス情報、端末識別用インストールID
  • 問い合わせ内容、障害情報、利用者が任意で提供した調査資料
  • 予約、宿泊者、料金、食事、客室、本人確認資料等の業務データ
  • Google OAuth認証トークンおよびGmailから取得した予約通知情報

通常の利用において、利用者の宿泊者データやGmailデータを当事業者へ 自動送信する機能は設けません。

3. 利用目的

取得情報を、契約・本人確認、代金請求、ライセンス発行・再発行、更新案内、 サポート、障害調査、品質・安全性の改善、不正利用防止、法令対応および 重要事項の連絡のために利用します。

4. Googleユーザーデータの取得と利用

JamooManagerは、利用者がGoogleの同意画面で明示的に許可した場合に限り、 Gmail APIの読み取り専用権限を使用します。対象は、CHILLNN、楽天トラベル、 じゃらんnet等から届く宿泊予約の新規・変更・キャンセル通知です。

取得したGoogleユーザーデータは、次の目的に限定して利用します。

  • 対象となる予約通知メールの検索および読み取り
  • 予約者名、宿泊日、人数、料金、食事、客室、予約番号、状態等の抽出
  • JamooManagerへの予約登録、更新、キャンセル反映および画面表示
  • 利用者が選択した帳票、顧客管理、売上、部屋割り等の関連機能

Gmailの送信、変更または削除を行う権限は要求しません。Googleユーザーデータを、 広告配信、販売、信用評価、プロファイリング、または予約管理と無関係な目的に 使用しません。

5. Googleユーザーデータの保存・共有

OAuth認証トークン、取得した予約通知および抽出した予約情報は、原則として 利用者が管理するWindows PC内に保存されます。当事業者が運営するサーバーへ Gmailデータを自動転送または保管する仕組みはありません。

Googleユーザーデータは、利用者の明示的な指示がある場合、法令に基づく場合、 または本ソフトの機能提供に不可欠な場合を除き第三者と共有しません。 Google APIから受け取った情報の利用は、Google API Services User Data Policyの Limited Use要件に準拠します。

6. 保存期間・削除・連携解除

Gmailから取り込んだ予約情報は、利用者が業務上必要と判断する期間、利用者のPCに 保存されます。利用者はJamooManagerのデータ削除、アプリのアンインストール、 または保存フォルダーの削除により、ローカルデータを削除できます。

Google連携は、 Googleアカウントの接続管理画面からいつでも解除できます。解除後は保存済みの認証トークンを削除することで、 JamooManagerからの新たなGmail取得を停止できます。削除方法が不明な場合は、 下記問い合わせ先へご連絡ください。

7. 宿泊者データ

予約、氏名、連絡先、宿泊日、人数、料金、食事、本人確認書類の画像等は、 原則として利用者が管理するWindows PC内に保存されます。利用者は宿泊者データの 取扱事業者として、利用目的、アクセス制御、バックアップ、保存期間、削除および 漏えい対応を適切に管理してください。

8. 外部サービス

利用者が連携機能を利用した場合、認証情報または予約関連情報が、Google、 Booking.com、CHILLNN、楽天トラベル、じゃらんnet、HeartRails Geo API等へ 送信される場合があります。クラウドOCRを利用すると読み取り対象画像がGoogleへ 送信されます。ローカルOCRを選択した場合、OCR処理のための画像送信は行いません。

9. 第三者提供・委託

当事業者は、法令に基づく場合、生命・身体・財産の保護に必要な場合、または本人の 同意がある場合を除き、当事業者が取得した個人情報を第三者へ提供しません。 業務を委託する場合は必要な範囲に限定し、適切な委託先を選定・監督します。

10. リモートサポート

リモート操作または画面共有は、利用者の明示的な同意を得て実施します。 宿泊者情報やGoogleユーザーデータは必要最小限の範囲で閲覧します。 調査用データを受領した場合は、作業完了後、法令または紛争対応上必要なものを除き 速やかに削除します。

11. 安全管理

当事業者は、アクセス権限管理、多要素認証、端末更新、暗号化通信、バックアップ、 ログ確認その他合理的な安全管理措置を講じます。利用者もWindowsアカウント、 Google・予約サイトアカウント、OAuth認証トークン、APIキーおよびバックアップ媒体を 安全に管理してください。

12. 開示等の請求

本人は、当事業者が保有する自己の個人情報について、利用目的の通知、開示、訂正、 追加、削除、利用停止、消去または第三者提供停止を請求できます。本人確認のうえ 法令に従って対応します。利用者のPC内だけに保存された情報については、当事業者が 保有していないため、利用者自身による操作が必要となる場合があります。

13. 改定

本ポリシーは、法令、Googleのポリシーまたはサービス内容の変更に応じて改定する 場合があります。重要な変更は適切な方法で通知します。
